# V212 model-free representational-diagnosis oracle results

## Bottom line

V212 passed every frozen integrity, scientific, decision, and access gate. The result establishes a complete model-free
oracle for the next research stage: candidate meanings are behavioral equivalence classes, representational status is
relative to explicitly frozen languages, and evidential status is tracked separately from both.

This is a mechanism result over a project-authored finite Boolean domain. It is not evidence that natural language,
human intent, real-world ontology truth, or language-model performance has been solved.

## Prospective integrity

The V212 design was frozen before the formal oracle ran. The design audit verified:

- the V211r1 parent was a frozen zero-model-eligibility result that authorized a new identifiable design;
- the complete eight-world, 256-behavior domain and the `L0`/`L+` representation languages were fixed;
- all 40 development-only recipes and all noncompensatory thresholds were fixed;
- the prediction worker accepted only public semantics and public cases;
- no language, external ontology payload, protected data, local/API model, training, mutation, registration, service
  call, side effect, or execution was authorized.

Predictions were hashed and frozen before the sealed truth was joined. The isolated prediction worker contained zero
truth paths and zero hidden-field references.

## Exact diagnosis

The oracle achieved:

| Measure | Result |
|---|---:|
| Records | 40 |
| Families | 10, with 4 records each |
| Complete behavioral hypotheses | 256 |
| Exact candidate-set accuracy | 1.0 |
| Evidence-status accuracy | 1.0 |
| Expressibility-set accuracy | 1.0 |
| Shadow-action accuracy | 1.0 |
| False primitive creation rate | 0.0 |
| False merge rate | 0.0 |

The ten families covered exact aliases, existing compositions, near-alias boundaries, broader/narrower relations,
missing operators, behaviors irreducible relative to the frozen languages, episode-grounded arbitrary symbols,
genuine ambiguity, contradiction, and outside descriptions.

This separation matters. For example, a behavior can be perfectly identified from evidence while still requiring a
missing operator or provisional representation. Conversely, every candidate may be representable while the current
evidence remains ambiguous.

## Equivalence, evidence, and boundary witnesses

The catalog contained 51 syntax programs that collapsed into 15 distinct represented behaviors. Equivalence-collapse
accuracy was 1.0, including identity rewrites and reversed commutative arguments.

The four ambiguous cases each retained exactly two behavioral candidates. The four outside descriptions retained all
256 candidates but were separately marked as outside the authorized clarification interface. The four contradictory
cases retained none.

Across the population there were 130,564 candidate pairs requiring a distinguishing witness: 130,560 from the four
outside cases and four from the deliberately ambiguous cases. Every pair had an exact distinguishing world, for a
boundary-witness coverage of 1.0. Every comparison-anchor case also received the correct boundary witness.

Reference evidence and complete observation evidence were both demonstrably necessary:

- reference-grounding sufficiency: 1.0;
- individual reference-fact necessity: 1.0;
- individual complete-observation necessity: 1.0.

Removing any tested necessary item reopened the candidate set rather than leaving a hidden singleton.

## Invariance

All frozen invariance checks scored 1.0:

- arbitrary symbol and reference renaming;
- evidence-order reversal;
- commutative argument reversal;
- behavior-preserving identity rewrites.

The oracle therefore depends on executable behavioral evidence, not incidental names or serialization order.

## Decision consequence

The exact candidate-set policy averaged `7.5`. Its actions included reuse, composition, missing-operator diagnosis,
provisional retention, boundary requests, contradiction deferral, and outside deferral as dictated by the diagnosed
state.

| Policy | Average value | Normalized regret |
|---|---:|---:|
| Exact equivalence set | 7.5 | 0.0 |
| Forced new primitive | -18.5 | 0.65 |
| Forced nearest merge | -24.5 | 0.80 |
| Closed-world `L0` | -15.0 | 0.5625 |
| Abstain always | -2.0 | 0.2375 |

Safe outside deferral had an advantage of `28.0` over making a semantic commitment. All 44 exact-policy terminal paths
were proper; there were no unsettled terminals or horizon escapes.

These controls establish the intended nontriviality: always inventing, always merging, forcing a closed-world
representation, and always abstaining are all materially worse than preserving the correct version space and acting on
its diagnosed structure.

## Research decision

The frozen branch is `V213_DESIGN_ELIGIBLE`.

V212 authorizes only the design of V213, a fresh role-separated programmatic concept population. It does not authorize
immediate population generation, external ontology payload reads, a local or API model, training, registration,
trusted-state mutation, service calls, action, or execution.

The next sequence remains:

1. V213: prospectively freeze a fresh programmatic concept population with separate generator, public-observation, and
   hidden executable-truth roles.
2. V214: run deterministic retrieval, parsing, bounded synthesis, equivalence collapse, contradiction handling, and
   exact residual accounting.
3. Only if a meaningful residual survives V214, preregister a bounded local LLM as a candidate generator and measure
   incremental oracle-class recall at a fixed candidate budget.
4. Reuse the existing sandbox and certificate-aware planner for any surviving provisional candidates; do not rebuild
   execution authority.

A separate metadata-first external-resource census may now be designed, but any ontology payload access requires its
own prospective lock and can support retrospective reconstruction or provisional staging only—not claims about the
correct meaning of a new speaker's utterance.
