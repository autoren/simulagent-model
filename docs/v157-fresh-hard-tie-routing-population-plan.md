# V157 fresh hard-tie routing population plan

## Purpose

V156 showed that explicit lexical metadata can solve synthetic requests already covered by the catalog. V157 creates the missing conditions before any new policy or model is run: uncatalogued paraphrases, cross-family relational ties, and genuinely insufficient requests.

The central architectural addition is a generic typed routing question, `Q70`. Its answer can identify one registered specific question or say `UNCLEAR`. It cannot produce a semantic witness, select a state, define a capability, prune hypotheses, or execute. A final state still requires the appropriate specific trusted binary answer.

## Population

The catalog contains six specific questions spanning municipal collection, transport deposits, public-service accommodations, environmental monitors, heritage records, and resilience grants. Each has a known left state and either novel-candidate or unsupported right state. `Q70` has six family-route options plus `UNCLEAR`, none with a state or witness.

Each of 48 groups has eight stages:

1. lexically decisive control;
2. independently authored uncatalogued paraphrase;
3. cross-family relational tie;
4. genuinely insufficient request;
5. trusted family-route answer;
6. trusted unclear-route answer;
7. trusted specific left answer;
8. trusted specific right answer.

The 384 fixtures are evenly divided between synthetic development and evaluation. Public rows hide strata, truth, compatibility, route targets, oracle queries, and witnesses.

## Gates and boundary

The audit must prove exact split/group/stratum completeness, zero exact conversation overlap with earlier controlled populations, valid generic routing with zero semantic witnesses, exact specific-witness routing, semantic fail-closure before the specific answer, malformed-event fail-closure, complete hypothesis retention, no candidate/proposal fields, and zero execution.

No retrieval policy or model is run in V157. Passing authorizes only a separately locked model-free development policy that must decide between a high-confidence specific question and `Q70`. Evaluation access, a local-model tie-breaker, APIs, training, calibration, induction, authority, action, and execution remain closed.
