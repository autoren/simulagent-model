# V206 fresh external analogue feasibility plan

## Question

Does a newly identified public source natively expose enough documented structure for a later, honest external test of the V205 mechanism?

## Why a new source census is justified

V76 searched for discovery-clean active-sensing confirmation of the earlier two-codebook mechanism and found no qualifying repository pair. V205 asks a materially different question: whether an explicit outside or invalid semantic regime makes safe deferral optimal when control consequences are terminally unavoidable. V206 therefore admits only repositories not present in the frozen exposure registry and focuses on recent open-world, abstention, sensor-failure, and active-belief benchmarks.

## Metadata-only boundary

The census pins each candidate's remote `HEAD` and fetches only its declared official README and license path. It stores hashes, byte counts, detected license family, marker evidence, and gate results—not the fetched text. It does not clone or archive a repository, open implementation or configuration files, read task examples, dialogues, utterances, or dataset records, inspect probability or reward arrays, or run a simulator, planner, policy, model, or API.

## Qualification contract

A candidate must document all of the following in the same official source family:

1. an open-world, outside, invalid, unknown, or abstention regime;
2. action-dependent information gathering;
3. an in-episode reference, calibration, or cross-sensor pathway;
4. a safe defer, abstain, refuse, or hold action;
5. a delayed state-dependent or irreversible consequence;
6. an exact simulator or validated generative likelihood path;
7. public reuse terms; and
8. source-native critical elements, without a project-added sensor, action, hidden regime, reward, or terminal rule.

Passive out-of-scope classification, answer-versus-abstain labels, active perception alone, or an executable sandbox alone cannot compensate for a missing gate.

## Candidates

The frozen candidates are AgentAbstain, OpenAgent, MIntRec2.0, FailureSensorIQ, Theory of Space, and ACEBench. Their selection used only public search snippets and repository landing descriptions. Exact repository heads and official files have not been fetched before lock.

## Decision

One fully qualifying repository-distinct family is sufficient to authorize a **separate** source-file structural-inspection preregistration. A negative census preserves V205 as a model-free mechanism and defers external grounding; it does not permit weakening the analogue contract or reusing exposed Tiger, RockSample, paint, maintenance, or V76 candidates.
