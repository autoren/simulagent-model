# V143 Oracle Certificate Policy Audit Plan

## Purpose

V143 verifies the semantics of V142 before any model run. Every decidable fixture receives the exact
singleton sufficient certificate. Every ambiguous fixture receives the exact two-choice insufficient
certificate. The deterministic finalizer must reproduce every frozen truth and every six-stage sequential
policy.

## Policy evaluation

The audit reports exact accuracy for each language class, compatible-set accuracy, query rate, final output
validity, false-known action, safe non-known action, and sequential cost using V136's frozen asymmetric loss
matrix and 0.30 clarification cost.

## Mutation boundary

Nine malformed certificate classes must fail closed to valid `A00` output. A separate well-formed but wrong
singleton must pass structural validation, explicitly demonstrating that the interface enforces syntax and
internal consistency—not semantic truth. That limitation remains for empirical evaluation.

## Decision

Passing authorizes only preregistration of one local, development-split certificate realization. It does
not authorize a model run directly, the frozen V142 test split, V134, external language, APIs, training,
induction, authority, action, or execution.
