# V84 Schema-Grounded Shadow Plan

V84 tests the next narrow generalization of the positive V83 boundary. A declarative typed schema
specifies two required slots, two choices per slot, and safe question prefixes. A generic module may
render a clarification for one slot or both slots, but the schema cannot select, rename, or execute a
policy action.

The frozen census contains four schemas: the V79 project workflow and three fresh homologous transfer
schemas. Each schema has three clarification targets, rendered canonically and through eight finite-
grammar styles, for 108 schema cases. The V79 bridge separately covers all six reachable clarification
nodes in all nine render modes, for 54 bridge cases. Policy fields, values, the operational
`none_of_the_above` hypothesis, and complete-belief execution certificates remain authoritative and
unchanged.

Twelve frozen invalid-schema mutations, thirteen unknown or malformed clarification requests, and
sixteen adversarial surface mutations must all fail closed. Valid-looking untrusted strings remain
non-deployable because provenance is part of the certificate. There is no fallback that guesses a
schema, slot, action, or surface.

V84 is model-free, synthetic, bounded shadow evaluation. It uses no original user language and
performs no real tool action. A pass can authorize only preregistration of a later local model as an
offline adversarial-input generator whose outputs are never deployable; it cannot itself authorize a
model call.
