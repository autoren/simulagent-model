# V92 Structured-LLM Architecture Assessment

## Decision

Freeze the current structured-language research branch with a **model-free authoritative runtime**.
No tested local-model role qualified for adoption, and V90 removed the remaining capacity/precision
uncertainty. An API comparator, LoRA, learned likelihood, search pruning, or execution authority would
therefore be an unregistered retry rather than the next step supported by evidence.

The retained architecture is:

1. deterministic typed-schema enumeration of every hypothesis, including operational `NONE`;
2. deterministic, immutable state accumulation and validation;
3. trusted canonical or finite-grammar clarification text through the V86-hardened boundary;
4. exact Bayesian belief updating and posterior-aware V79 planning;
5. complete-belief execution certification and fail-closed shadow evaluation;
6. no LLM or API dependency in the decision path and no real tool or service execution.

## Evidence chain

V77/V77r1 are correctly retained as execution-inconclusive. V78 produced a valid negative benchmark-
design result, and V79 corrected the prospectively isolated terminal-utility omission. V79 passed all
23 gates and independently verified clarification, `NONE`, MAP and act-immediately regret, safe unknown
continuation, exact posterior-aware planning, and execution certification.

The subsequent local-model roles were all bounded and all nonqualifying:

| Role | Frozen stage | Result |
|---|---:|---|
| direct typed candidate set | V80 | failed candidate accuracy and OOD exactness |
| factorized semantic compatibility | V81 | failed ambiguity and OOD gates |
| clarification wording | V82 | strict raw validity `1/24`; disabled |
| offline adversarial generator | V85 | insufficient validity, diversity, and coverage |
| external intent/state candidate set | V88r1 | failed active-intent and state gates |
| 4B/27B, Qwen3.5/Qwen3.8, 4/8-bit capacity comparison | V90 | zero qualifying conditions |
| complete-search rank-only scheduler | V91 | worse than deterministic exact-match grammar |

V83, V84, and V86 establish the deterministic replacement boundary. V87 and V88r1 add externally
authored Schema-Guided Dialogue language under permanently non-executable shadow evaluation, but do
not establish open-world safety or deployable human-language understanding.

Across the frozen model stages, the project used 11 local model loads and 401 generations. It used zero
LLM API calls, adapter-training runs, real tool/service calls, and external side effects.

## Controls and separation of concerns

The frozen sequence contains exhaustive enumeration, deterministic grammar, lexical retrieval,
direct-action/act-immediately, MAP, ask-always, oracle-candidate/state, and oracle-interpretation
controls. Candidate recall, schema conformance, canonicalization, state-key recovery, posterior-aware
planning, control regret, and execution certification were measured separately.

That separation is important for the negative conclusion. Model-conditioned posterior integration and
downstream model-conditioned action regret were not run after candidate generation failed its
noncompensatory gates. Likewise, model-generated mechanic/action hypotheses were not authorized after
the narrower semantic interface failed. These are protocol-compliant stopped stages, not evidence that
those stages succeeded or failed.

V91 tested the only remaining safe runtime role without allowing candidate deletion. Deterministic
completion retained the entire hypothesis set and `NONE`, and all 480 planner permutations were action-
and value-invariant. The model then achieved MRR `0.66667` and mean rank `1.9375`, versus `0.75260` and
`1.60938` for the best deterministic control. It supplied no scheduling benefit.

## Model-usage policy

Qwen3.5 4B may remain only as a historical low-cost shadow baseline. The Qwen3.5/Qwen3.8 27B and 8-bit
conditions are frozen nonqualifying evidence, not candidates for a cascade or ensemble. No current
result justifies an API dependency, adapter training, learned confidence/likelihood, hypothesis pruning,
or any model authority over state, belief, action, or execution.

A future LLM study would need a materially new scientific role, fresh evidence, prospective
noncompensatory gates, and a failure mode that cannot remove the true hypothesis or affect execution.
It should not reopen or tune V80-V91.

## Claim boundary

The positive claim is limited to a bounded, typed, exact, shadow-only decision architecture and to the
failure of the tested local-model roles under their registered conditions. The work does not establish
open-world language understanding, general LLM unreliability, real-service safety, long-horizon
scalability, or human-language deployment.
