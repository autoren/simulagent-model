# V123 Fresh-population Availability Audit Plan

V123 will count unused MASSIVE test candidates after excluding every V101, V112, V114, and V115
identifier. It will use only the frozen text-free source inventory and emit aggregate class/scenario counts.

The preregistered retrieval-selectivity transfer requires at least 32 records per class and both novel-valid
scenarios. V123 will not shrink that requirement after inspecting availability. It reads no language or
individual candidate, evaluates no signal or trigger, loads no model, and executes nothing. If the pool is
insufficient, the only permitted successor is a separately locked feasibility audit for a new controlled
open-set source.
