# V203 independent confirmation-feasibility plan

## Question

Does a genuinely partition-independent, licensed, externally authored population exist for confirming V202's exact
14-contract top-3-plus-`OTHER` controller without reusing V198 protected evidence?

## Frozen census

V203 reads the pinned SGD archive once, but only the three schema metadata files. It computes the unchanged V183
semantic contract hash for every train, dev, and test service-intent definition and joins those hashes to the frozen
text-free candidate inventory. Every V183 and V191 source record and partition-qualified dialogue is excluded.

The only selectable family is exact-contract train/test evidence. It must cover all 14 contracts with at least six
unique partition-dialogue keys per contract, singleton source-annotation linkage, no prior overlap, complete target
expressibility, and the already frozen licensed-human-source gate. A mixed dev/train/test remainder is reported only
as a diagnostic and cannot qualify. The frozen Taskmaster and MultiWOZ V87 candidates remain ineligible unless their
already audited source gates and an exact 14-contract mapping exist; V203 cannot invent such a mapping from similar
intent names.

## Boundary

Schema descriptions are used only inside the already frozen semantic hash. No utterance, dialogue history, slot
value, protected language, raw model output, or policy score is read or emitted. There is no model/API/training,
selection, registration, mutation, service call, side effect, action, or execution.

A positive result authorizes only a separately locked text-free population selection. A negative result parks B1 as
development-only and authorizes only preregistration of the richer model-free POMDP track.
