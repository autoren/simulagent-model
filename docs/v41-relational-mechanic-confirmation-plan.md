# V41 declared-scope relational-mechanic confirmation

## Claim

V41 is the population-level end-to-end confirmation of the current research claim: a frozen declared-language compiler and an executable symbolic schema inducer transfer across unseen one-step relational mechanics under a declared Boolean ontology.

It does not test open paraphrase, ontology discovery, sequential state mutation, stochastic or delayed effects, active intervention selection, or general world-model learning.

## Frozen components

The V39 compiler is frozen by V39 and independently confirmed by V40. The V22 typed relational ontology, finite lifted DSL, program enumerator, partial-information executor, and truth semantics are also immutable. V41 may add only an independently audited population generator, a controlled-language renderer, deterministic graph assembly, and evaluation plumbing.

V28 marginal inference is not used. It addressed uncertain neural graph scores; V41’s registered question is whether the now-exact declared interface can populate the symbolic system. Adding posterior machinery would obscure this decomposition.

## Fresh population

The suite has exactly 40 mechanics: ten from each of unary selection, relation-conditioned behavior, two-hop composition, and existential aggregation. Each family contains three one-bit and seven two-bit mechanics. Every target program key used anywhere in V22 is excluded before selection, leaving unseen lifted behaviors rather than new worlds for old mechanics.

Each mechanic receives identifying support traces and the seven established relational query axes: binding recombination, relation orientation, graph topology, entity-count extrapolation, partial observation, distractor invariance, and permutation equivariance. Support is capped at 24 traces. Mechanic episode is the statistical unit.

Every state atom is rendered as one V39 controlled-language packet with declared predicate and operator ontologies. Semantically equivalent sign/operation realizations are balanced. The frozen compiler must recover each atom and truth status before deterministic graph assembly. Any compiler abstention or incomplete graph triggers the conservative full-outcome policy.

## Gates

Clause parsing, support graph recovery, query graph recovery, schema recovery, target retention, transition-set exactness, complete-episode exactness, every family, and every query axis must all equal 1.000. Empty version spaces must equal 0.000.

An empirical state/outcome lookup control must remain at or below 0.950 transition-set exactness. This prevents a passing result from being interpreted as lifted mechanic induction if literal state memorization already solves the suite.

## Decision

- All gates pass: accept the declared-scope relational-mechanic claim and begin a separate architecture-breaking benchmark for sequential mutation, stochasticity, delayed effects, interventions, and open concepts.
- Language or graph gates fail: reject end-to-end transfer without repairing and repeating V41.
- Graphs pass but schema/execution fails: revisit symbolic hypothesis coverage in a new experiment.
- Lookup exceeds its ceiling: do not attribute success to lifted schema induction.

There is one sealed confirmation evaluation, no model access, no V28 replay, no selection, and no outcome-driven repeat.
