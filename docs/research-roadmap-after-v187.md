# Research roadmap after V187/V187r1

## Boundary now established

V183–V186 show that the externally grounded SGD branch has a coherent 14-contract ontology and an identifying finite
typed question codebook. V185 separately shows that passive character/token schema similarity cannot safely select a
cheap candidate confirmation. V187 shows that, without a useful passive proposal, target-blind clean binary questions
are not cost-effective at the frozen interaction costs.

The V187 comparison is decisive for this design:

- exact adaptive, greedy information gain, optimal fixed open loop, and always-generic clarification all cost 0.40;
- exact typed-only completion is zero;
- source order costs 0.625 and completes only one third without generic fallback;
- the target-informed oracle costs 0.10, but is non-operational because it selects a confirmation using hidden truth.

V187r1 is a verification-only repair. It corrects the verifier's expectation for one frozen presentation field and
does not change or rerun any policy, target path, gate, or decision.

## Closed successors

Do not run common-shock stress, one-corruption analysis, triple repetition, protected identity confirmation, or a local
or API answer proposer on the V187 binary policy. Those steps were conditional on clean economic value. Redundancy
cannot create value when the clean Bellman policy already declines to ask.

Do not repair V187 by changing costs, relaxing gates, extending the horizon, using protected language, or treating the
target-informed oracle as deployable.

## Active next track: clarification-channel economics frontier

The next study is text-free and structural. It should explain how much information the channel must deliver before a
new experiment is justified.

1. **Unrestricted binary lower bound.** Compute the optimal prior-weighted prefix-code depth (Huffman bound) for the
   frozen 14-contract development prior, plus entropy and integer-depth controls.
2. **Frozen-codebook exact-depth bound.** Remove generic clarification and solve the unrestricted-horizon exact
   decision tree using only the 25 distinct V186 binary partitions. Report expected, minimum, maximum, and per-target
   depth, and prove target retention and exact leaves.
3. **Cost frontier.** Holding generic clarification at 0.40, compute the exact Bellman policy over a prospectively fixed
   rational grid of binary-question costs. Identify every policy breakpoint and the largest cost that yields positive
   value, typed completion, and adaptive-over-open-loop advantage. This is diagnosis, not authorization to revise V187.
4. **Bandwidth comparison.** Define candidate multiway questions only from the same frozen semantic attributes (for
   example domain or normalized intent concept), price them by an explicit information/cognitive-cost rule fixed before
   scoring, and compare their theoretical frontier with binary and generic channels. Do not assume that one categorical
   answer has the same cost as one bit.
5. **Successor decision.** A new clean planner may be preregistered only if the frontier identifies a non-arbitrary,
   prospectively defensible channel/cost region. Otherwise freeze the clarification track and return to population or
   observation design.

## Later language/model track

The 0.10 target-informed gap motivates—but does not authorize—a non-authoritative proposal condition. A future model
study must use a distinct development population and must show that its shadow proposal changes question choice beyond
V185's failed similarity views. Model outputs may rank questions or increase deferral only. They may never accept or
prune authoritative hypotheses, register a capability, mutate trusted state, call a service, act, or execute.

## Durable boundary

Source annotations instantiate oracle answers only for simulation. They are not human judgments, deployed sensors, or
model evidence. Protected utterance language remains sealed throughout the channel-economics track.
