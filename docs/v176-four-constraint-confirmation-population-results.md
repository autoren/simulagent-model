# V176 four-constraint confirmation population results

## Verdict

V176 passed every preregistered population gate and is frozen before confirmation scoring.

The complete frame contains 1,120 four-constraint states, all retained. Every state has exactly 16 candidates. Of
these states, 135 contain alias, composition, and `provisional_primitive` candidates and are therefore compatible with
the unchanged V167/V175 three-class prior. The eligible states contain 2,160 target cases: 138 alias, 180 composition,
and 1,842 provisional.

Every target receives the unchanged class-balanced weight: one third of state-level prior mass per class, uniform
within class. Weights normalize exactly in every eligible state.

## Freshness and limitation

All 2,160 exact target-context signatures are unique and have zero overlap with V172. A target-context signature is
the canonical initial constraint signature plus the target's complete eight-valuation truth table. V176 therefore
tests the unchanged planner on new exact evidence contexts.

This is not unseen-concept evidence. The 204 distinct target candidate identities in V176 all also occur in V172.
That reuse is expected because both populations use the same fixed 256-candidate ontology. The valid claim is context
generalization within a fixed ontology, not concept or language generalization.

## Access and authority boundary

Population construction computed zero policy scores and ran zero sandbox transactions. There was no model or API use,
manual judgment, evaluation-record access, training, ontology registration, trusted real-state mutation, service call,
side effect, or execution.

A passing V176 result authorizes only a separate preregistration of one unchanged V175 confirmation over all 135
eligible states and all 2,160 targets. It does not authorize immediate scoring, target selection, policy tuning,
registration, real effects, or deployment.
