# V86 Partial-Option Validator Plan

V86 is a narrow model-free correction prompted by the independently verified V85 diagnostic. The
existing V84 certificate rejects the complete alternative phrase from an unrequested slot, but it can
miss a single injected option. V86 retains the same frozen schemas, typed requests, canonical and finite-
grammar strings, V79 bridge, and provenance policy while additionally forbidding every individual option
surface from an unrequested slot.

The exact census reruns all 108 safe schema renderings and all 54 V79 bridge renderings without changing
their text. It retains the sixteen original unsafe controls, adds sixteen exhaustive partial-option
injections across four schemas and two requested slots, and directly replays the one V85 registered false
positive.

No model is loaded or generated. V85 is not rerun, and its outputs cannot become deployable. A V86 pass
only supersedes the weak content-certificate rule in future bounded shadow integration.
