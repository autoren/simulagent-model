# V45 declared delayed-language grounding

## Why this is next

V44 established exact deterministic delayed-effect induction and execution with a hidden event queue. V45 now changes only the exposed representation of those sealed cases. It does not add stochasticity or a new mechanic population.

## Paired interface test

The 40 V44 mechanics, 46 support sequences, 960 queries, 480 wait-placement pairs, tick semantics, and targets are immutable. States are rendered with fresh declared predicate and operator lexicons, entities receive fresh episode namespaces, and ordered actions receive fresh declared cues.

State packets use the frozen V39 compiler and the canonical duplicate-safe V43r1 graph comparator. `pulse` and `route` follow the frozen V43 bound-action contract. V45 adds only a declared zero-argument `wait` command to that grammar. Step ordinals remain explicit, contiguous, and one-based.

Unknown cues, malformed state packets, wait commands with arguments, missing or duplicate ordinals, and ambiguous templates must fail closed. The frozen V44 queued reasoner receives only compiled states and actions.

## Gates and controls

All state clauses, canonical graphs, bound actions, wait actions, complete sequences, and safety challenges must be exact. The compiled pipeline must exactly reproduce target retention, schema recovery, intermediate and final observations, every family and length, and all wait-placement counterfactuals.

The frozen collapsed-delay and end-flush controls must each remain at or below 0.850. Literal language lookup must remain at or below 0.950.

## Decision

- All gates pass: accept declared delayed-interface composition within the paired scope and preregister an oracle stochastic-transition foundation.
- Language fails: repair only the relevant compiler.
- Language passes but execution fails: audit translation while leaving V44 frozen.
- A control passes: repair the benchmark or control before advancing.

V45 is non-final, model-free, and not an independent population replication. Open paraphrases, stochastic effects, active intervention selection, and open ontologies remain excluded.
