# V208 external behavioral-abstention source census plan

## Question

Does a fresh external source expose enough nonlanguage structure to preregister a balanced, text-only, pre-execution act-versus-abstain shadow evaluation with deterministic gold labels?

The six-source roster was fixed from official landing-page previews before any recursive repository tree, dataset revision, or card-metadata census. It includes OverSearchQA, AbstentionBench, AbstainEQA, HiL-Bench, ClarifyCodeBench, and Ask or Assume. AgentAbstain is excluded because V207r1 already established its source-interface failure.

## Evidence boundary

The locked census may pin repository and declared external-dataset HEAD revisions, read GitHub repository-object metadata, enumerate recursive GitHub tree paths, and read Hugging Face card-data object metadata. It may not fetch a README or other blob body, license text, dataset tree, data row, task payload, prompt, instruction, illustrative example, dialogue, rationale, response, or execution trace.

One OverSearchQA example appeared incidentally in the official landing-page preview during discovery. That exposure is recorded before the lock; no candidate task payload was opened, and the roster and gates are fixed without using the example's content.

## Gates

A candidate must independently pass every gate: immutable licensed code/data revisions; at least 40 units, 20 paired controls, and two scenarios; paired or matched controls with an explicit machine-readable pair identifier; explicit pre-execution phase identity; a deterministic act/abstain gold field independent of an LLM judge; prompt/label separation; balanced controls; and a text-only shadow path requiring no runtime interaction.

Prose claims that data are paired do not substitute for an explicit pair-identity field. A collection of only underspecified positives does not substitute for matched act controls. Runtime blockers, visual histories, code execution, simulated users, or judge-mediated labels do not qualify for the planned text-only pre-execution study.

## Decision

A positive result authorizes only a separately locked identifier-selection and extraction design. A negative result parks external behavioral abstention rather than weakening the gate or synthesizing pair labels. No model, API, tool, service, training, authority, action, or execution is authorized.
