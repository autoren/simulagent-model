# V146 fresh controlled codebook-scoring population plan

V146 creates a fresh project-authored population for a future score-all-certificate-codes experiment. It uses new catalog IDs, domains, templates, slot values, and conversations rather than reusing V142 development or opening V142 test.

The topology remains controlled and independently checkable: nine choices, six contrastive families, eight groups per family, and six stages per group. Four groups per family are development and four are test. Every ambiguous row has exactly its registered pair as compatible; every decisive row has exactly one compatible choice. Public fixtures expose only the conversation, split, fallible presented candidate, and fixture ID.

The design audit must prove exact counts, public/hidden alignment, absence of hidden labels from public rows, exact codebook coverage, no exact conversation overlap with V135 or V142, full authoritative retention, and zero model, API, training, or execution access.

Passing authorizes only a separately frozen scoring-protocol preregistration. It does not authorize a model run or test access.
