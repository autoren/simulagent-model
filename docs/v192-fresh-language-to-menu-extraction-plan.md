# V192 fresh language-to-menu extraction plan

## Purpose

V192 performs the single exact extraction authorized by V191. It reconstructs each of the 84 frozen conversation
prefixes through its selected user turn and joins them only to V191's public opaque identities. Fourteen missing
controls receive null conversation.

## Observable boundary

Each output record contains only:

- opaque record ID;
- the unprotected development role;
- observation availability; and
- speaker/utterance turns through the selected user request.

The artifact excludes source candidate and dialogue identifiers, services, intents, domains, truth kinds, target
contracts, compatibility sets, semantic frames, actions, states, slot values, and spans. Hidden targets remain in the
separate immutable V191 artifact and are never joined into a future proposal input.

## Decision

An exact pass authorizes only preregistration of a shadow menu-output interface and a model-free oracle/retention cost
frontier. It does not authorize immediate scoring, a local/API model, protected access, ontology registration or
pruning, trusted mutation, action, or execution.
