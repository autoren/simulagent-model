# V43 declared sequential-language grounding

## Why this is next

V42 established that the minimal stateful extension can exactly identify and execute deterministic persistent mechanics over ordered action sequences. Its memoryless control reached only 0.372, so the benchmark genuinely required state carried from one action to the next. V42 did not expose language.

V43 changes only that interface. It asks whether controlled text descriptions of states and ordered actions can populate the already-frozen V42 symbolic reasoner without changing its DSL, program registry, support cases, queries, or targets.

## Paired design and claim boundary

The 40 sealed V42 mechanics, 43 support sequences, and 960 queries are reused as fixed semantic cases. Every public entity receives a fresh episode namespace. Every state atom is rendered through a fresh declared predicate lexicon and operator cue table, and every action is rendered through a fresh declared action lexicon with explicit step ordinals. The compiled pipeline is paired against V42 on identical underlying cases.

This is deliberate reuse, not an independent population replication. Pairing holds the scientific content fixed while changing the exposed representation. A pass supports exact composition of a declared sequential-language interface with the V42 reasoner. It does not support open-ended natural language, ontology discovery, or arbitrary temporal world models.

## State and action compilers

State packets use the frozen V39 compiler. True, false, and explicitly unknown atoms are expressed with balanced sign/operation realizations. Initial states and every observed support step are compiled independently before graph assembly.

The V43 action compiler receives a declared action ontology. It accepts actor-first and target-first templates, maps fresh episode cues to the fixed action identifiers, checks typed entity arguments, and preserves only explicit, contiguous, one-based step ordinals. Unknown cues, ambiguous templates, missing or duplicate ordinals, and malformed commands must cause abstention.

The frozen V42 reasoner receives only the compiled symbolic states and actions. Failed compilation yields the conservative full outcome set rather than a guessed parse.

## Evaluation and controls

State-clause parsing, state graphs, action commands, complete action sequences, and safety abstention must all be exact. The compiled pipeline must also retain the target program, recover the schema, avoid empty version spaces, and reproduce all next and final observations for every family and sequence length, including all causal order counterfactuals.

An order ablation reduces each action sequence to a canonical bag order. It must score no more than 0.850 on causal order counterfactuals. A literal language-sequence lookup must remain at or below 0.950 final exactness. These controls prevent a pass from being attributed to text memorization or order-insensitive matching.

## Decision

- All gates pass: accept exact declared-interface composition within scope and preregister an oracle-first deterministic delayed-effect benchmark.
- State or action parsing fails: repair only that declared compiler before touching the reasoner.
- Parsing passes but schema or execution fails: audit the translation boundary; the V42 reasoner remains frozen.
- An inadequacy control passes: redesign the corresponding control before making the stronger claim.

V43 is non-final and language-model-free. Stochasticity, delayed effects, active intervention choice, open ontologies, and open paraphrases remain outside the experiment.
