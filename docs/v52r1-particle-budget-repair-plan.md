# V52r1 preregistration: particle-budget commensurability repair

The first implementation-only stochastic fixture revealed that V52’s proposed budgets 32, 128, and 512 are all divisible by four. The frozen probability vocabulary is exactly 1/4, 1/2, and 3/4. With systematic resampling, many common branch allocations can therefore be represented with zero sampling discrepancy at every budget. That would weaken the scientific test of particle convergence, collapse, and random-stream independence.

No V52 implementation lock, population, sealed result, or evaluation attempt exists. V52r1 changes only the budgets to 31, 127, and 509 and makes 509 the scale-stress budget. These values remain in the same computational cost class but are coprime to the probability denominator. All programs, population sizes, seeds, inference targets, controls, metrics, gates, firewalls, and downstream authorization remain exactly as frozen in V52.
