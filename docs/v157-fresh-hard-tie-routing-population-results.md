# V157 fresh hard-tie routing population results

## Verdict

V157 freezes a fresh synthetic population for testing safe generic routing under hard lexical conditions. It is a benchmark-design result only, not policy performance, model performance, external transfer, or open-world deployment evidence.

The population contains 384 fixtures in 48 complete eight-stage groups, evenly split between development and evaluation. Each of four request strata has 48 fixtures: lexically decisive controls, uncatalogued paraphrases, relational ties, and insufficient requests. Six specific trusted questions coexist with generic route query `Q70`.

All design gates passed. Generic route answers were structurally valid on all 96 route fixtures but produced zero semantic witnesses and left the final state at fail-closed `A00`. All 96 specific answers produced exact trusted witnesses. Requests, route-only answers, and malformed events remained semantically fail-closed; the complete authoritative state set was retained; candidate fields and execution were zero. Canonical conversation overlap with V135, V142, V146, V149, V152, and V155 was zero.

No policy was scored and no model, tokenizer, API, training, service, action, or execution was used.

Freeze the design decision:

`freeze_fresh_hard_tie_routing_population_authorize_separate_model_free_development_policy_preregistration_only`

The only authorized successor is a prospectively locked model-free development policy with an explicit score/margin rule for choosing a specific question versus `Q70`. V157 evaluation and any model/hybrid condition remain closed.
