# V181 five-constraint robust-confirmation population results

## Verdict

V181 passed every preregistered population gate and is frozen before robust confirmation scoring.

The complete frame contains all 1,792 five-constraint states. Every exact version space has eight candidates. Sixty-six
states contain alias, composition, and `provisional_primitive` candidates and are therefore compatible with the
unchanged V167/V180 three-class prior. Those states contain all 528 frozen targets: 66 alias, 72 composition, and 390
provisional primitive.

Each class receives one third of state-level prior mass, distributed uniformly within that class. The weights normalize
exactly in every eligible state. No state or target was selected using a planner, policy, routed risk, or sandbox result.

## Freshness and limitation

All 528 target-context signatures are unique. Exact overlap is zero with both the V172 three-constraint targets and the
V176 four-constraint targets. A signature combines the canonical five-constraint evidence context with the target's
complete eight-valuation truth table.

The 111 distinct target candidates all appeared in both earlier populations. This is intentional because the ontology
is fixed. V181 supports a future test of new evidence contexts, not unseen concepts, language generalization, or an
external observation source.

## Access and authority boundary

Population construction computed zero planner-policy scores and ran zero sandbox transactions. Manual judgment, model
and API access, training, ontology registration, real sensor or service calls, trusted real-state mutation, external
effects, and execution all remained zero.

A pass authorizes only separate preregistration of one unchanged V180 robust confirmation over all 66 eligible states
and all 528 targets. It does not authorize immediate scoring, selection, tuning, model use, registration, real effects,
or deployment.
