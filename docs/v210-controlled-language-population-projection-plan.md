# V210 fresh controlled-language population and projection plan

## Purpose

V209/V209r1 proved that exact open-world planning has value when controlled utterances are generated by a known probabilistic channel. V210 asks the next interface question: can that channel be turned into a fresh, role-separated language population with an auditable truth firewall and a truth-blind deterministic projection residual?

This is still model-free. The population is project-authored and finite. It tests experimental infrastructure, not general natural-language understanding.

## Population contract

Each role crosses three semantic regimes, two task states, five valid clarification contexts, and three semantic observation IDs. Every cell is represented by a matched three-record group:

1. an explicit direct marker;
2. a naturalized matched paraphrase; and
3. an opaque vocabulary renaming.

This yields 90 groups and 270 records per role. The census includes every observation support point and stores the exact V209 source probability; it is not a random empirical-frequency sample.

Development and protected roles use different seeds, identifiers, template skeletons, context phrases, and label lexicons. Surface and truth records are written to separate artifacts. Surface records contain identifiers, group/context metadata, counterfactual type, construction family, and utterance. Truth records contain the hidden regime/state, action, history, semantic observation ID, and source probability. Regime, state, and probability never appear in the surface artifact.

Protected artifacts are generated and automatically audited, but protected surface text cannot be manually displayed or read by the projection baseline.

## Deterministic projection

The frozen projector reads only development `record_id` and `utterance`. It recognizes the explicit `<OBS=...>` direct marker and maps it to the fixed semantic alphabet. Every paraphrase or opaque form becomes `ABSTAIN`. Truth is joined only after prediction for scoring.

The intended result is 90 safe accepted records, 180 truth-blind residual records, perfect accepted accuracy, and no false acceptance. Residual membership must be computable from predictions alone and retain every regime, state, context, and observation across both non-direct counterfactual types.

This narrow projector is a safety/control baseline, not a claim that simple parsing solves language understanding.

## Noncompensatory gates

V210 requires exact counts and balance, record/full-factor uniqueness, role-disjoint identifiers and groups, zero role template/label overlap, zero hidden-truth leakage into surface fields, exact counterfactual truth and probability agreement, exact opaque-renaming mapping, complete truth/surface round-trip, normalized probabilities, deterministic byte-for-byte regeneration, and zero fallback.

Projection gates are exact rather than averaged. Access gates prohibit protected baseline reads, protected manual reads, external language, models, APIs, training, ontology/trusted-state mutation, services, side effects, action, and execution.

## Decision boundary

A positive V210 authorizes only a separate deterministic development-baseline design. It does not authorize opening protected surface text or running a local/API model. Any later model residual, prompt, parser, runtime, reasoning budget, calibration method, fallback, and protected transfer must be frozen in later experiments.
