# V55r1 preregistration: delayed-consequence adequacy confirmation

V55 remains a valid failed experiment: 19 of 20 gates passed, while removing every two-tick effect changed neither root action qualification nor root value on any of 32 sealed tasks. The post-result localization used no new planner calls. It found that only one of eight latent templates had a two-tick branch, only one task paired that generating truth with a goal on the affected predicate, and the delayed effect had a same-target deterministic immediate substitute. The analytic fixture proved delivery timing but not decision relevance.

V55r1 is a separate supplementary confirmation of the single failed dimension. It does not rerun, relabel, or reinterpret V55. The generic planner, belief update, horizon, observations, rewards, action costs, action enumeration, exact quadrature, independent scalar reference, policy evaluator, and firewalls remain unchanged.

The sole substantive repair is task support. V55r1 defines eight planning-specific latent templates. Four contain a stochastic effect delivered two ticks later, two deliver one tick later, and two apply immediately. Every stochastic branch changes a bindable `active` atom with unknown continuous theta. Deterministic effects are distractors on `marked`, `ready`, or `linked`; no template has a deterministic immediate effect on any `active` atom. Thus the two-tick effect cannot be replaced by an immediate same-target action.

Sixteen new tasks are balanced two per generating template and eight per history class. Public goals are exactly balanced across entity and Boolean value, shuffled from a seed independent of truth assignment. Before the query history is simulated, both `active` atoms are set opposite the public goal value. This creates a need for control without conditioning the goal on the hidden generating program. Public histories must be fresh against V49–V55.

The causal counterfactual changes only the due time of two-tick branches, moving them beyond the three-action horizon. A task is sensitive when the primary root action falls outside the counterfactual optimal set or the root value changes by more than `0.001`. At least two of sixteen tasks must be sensitive, including at least one from each history class. This is stricter at the population's discrete resolution than V55's unchanged conceptual minimum of ten percent.

Before population construction, exhaustive known-model fixtures must establish decision relevance for all four delay-two blueprints—not merely temporal visibility. The implementation audit must also confirm unique valid templates, one theta branch per template, absence of active-target deterministic substitutes, complete canonical actions, exact primary/scalar agreement, independent policy agreement, and intact truth/future-observation firewalls on altered-seed fixtures.

Only a full V55r1 pass may be combined with the nineteen frozen V55 passes to authorize preregistration—never execution—of symbolic and probabilistic policy verification. V55 itself remains failed in all reporting. Formal verification, approximate or learned search, longer-horizon claims, language grounding, model access, and training remain blocked.
