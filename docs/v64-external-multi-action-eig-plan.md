# V64 preregistration: external multi-action expected information gain

## Purpose and boundary

V64 qualifies the next benchmark and exact acquisition reference by asking whether exact,
history-adaptive one-step expected information gain (EIG) makes a real choice among multiple
navigation interventions and learns unknown dynamics more efficiently than matched fixed and
random designs. It is anchored to POBAX's pinned nonterminating 4x3 model at
commit `a5e1d62d14e4efe783885b9d4f19cffa2a568eec`. POBAX supplies the known transition,
observation, reward, initial-state, and discount arrays; it does not supply the unknown-dynamics
family or an active-design result.

The project-authored uncertainty layer represents actuator failure. A commanded direction uses the
pinned transition kernel for that command with probability theta. Otherwise it uses the pinned
kernel for the clockwise or counterclockwise adjacent command, according to a hidden episode-level
identity. Identity has a balanced prior and theta has a scaled Beta(2,2) prior on `[0.60, 0.95]`.
The current maze state is a nuisance latent integrated out exactly.

This stage is exact active system identification, not approximate-posterior portability and not
reward planning. The adaptive policy is
myopic: after every observation it recomputes one-step mutual information about joint identity and
theta for all four commands. It is not a multi-step Bayes-optimal experimental-design policy.

## Locked comparison

All policies start from the same pinned prior and receive one source observation after each
equal-cost command. The adaptive EIG policy is compared with an open-loop `n,e,s,w` cycle and a
uniform random command policy at budgets 1, 2, 4, 6, and 8. The primary budget-8 measure is mean
posterior KL from the joint identity-theta prior. Paired replications share static latents but use
separate, frozen policy-specific transition streams so action-dependent trajectories cannot alias
their random draws.

The exact selection benchmark contains 192 fresh public histories: 32 at each prefix length zero
through five, all generated by a truth-independent uniform behavior policy. Every generated record
is retained. Neither EIG spread nor the selected action may be used to accept, reject, or replace a
record. Candidate code is checked against a structurally separate scalar oracle over all four
commands and all six observations.

The paired adaptive comparison contains 512 fresh prior-predictive replications, exactly balanced
over actuator identity. A separate 256-replication adaptive SBC suite checks that conditioning on
actions selected from public pre-outcome histories has not broken posterior calibration.

## Advancement gates

Exact candidate-oracle agreement, probability normalization, information identities, calibration,
truth/outcome firewalls, stream separation, and control detection are noncompensatory. At least half
of selection histories must have an EIG spread above `0.001` nats, at least two commands must be
strictly optimal somewhere, and no command may exceed 90% of selections. Mean oracle EIG must beat
uniform random by `0.003` nats and the fixed cycle by `0.002` nats. At budget eight, the lower bound
of the paired 95% interval for adaptive information gain minus each baseline must exceed `0.02`
nats.

A full pass authorizes only preregistration of a separate stage that computes EIG from the frozen
pooled three-repeat SMC² posterior and compares its selections and regret with this exact oracle at
multiple inference budgets. That later stage must report both the deployed pooled ensemble and
single-repeat diagnostics, as well as inference latency and particle cost. An exact V64 pass alone
does not establish approximate active-inference portability.

Failure of the efficiency gates stops this active-design claim; it does not authorize changing the
family, policies, population, or gates after population construction. Reward planning and
cost-sensitive information-versus-task-utility tradeoffs remain later questions. Formal
verification, V58 human-language work, simulated human substitution, model access, and adapter
training remain forbidden.

## Current authorization

This document and its config authorize only implementation and mutation audit of the exact EIG
machinery. They do not authorize construction of either population or any V64 evaluation.
