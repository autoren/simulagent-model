partition. Its eleven-choice universe contains six declared intents, three valid-undeclared composites from
banks, flights, and media, one unsupported alarm composite, and one insufficient-evidence control.

collisions with the six declared choices. This removes the specific service-name confound identified by V133.
No dev utterance, dialogue history, slot value, model output, or raw schema description was emitted or
manually inspected.

This is not new language or model evidence. V134 is frozen as a future benchmark asset only. The current
authorization explicitly forbids extracting its selected language or running a local or API model. Protected
access, induction, richer planning, training, authority, actions, and execution remain closed pending a new
