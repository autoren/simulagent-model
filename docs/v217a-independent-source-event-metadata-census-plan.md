# V217A independent-source event metadata census plan

## Purpose

V216 is formally negative and cannot authorize its planned deterministic successor. V217A asks whether a different,
unopened OBO-compatible source family visibly supports a better retrospective open-world language population before
any new ontology body is downloaded.

The candidate family names—Mondo, Gene Ontology, and Cell Ontology—were fixed in the post-V216 roadmap. Exact official
metadata URLs, evidence fields, eligibility rules, selection priority, and the stop rule are frozen here before reading
source-specific release metadata. This is not blind family discovery, but candidate payload contents and formal source
scores remain unopened.

## Frozen sources and evidence

Each source unit has exactly three official endpoints: its OBO Foundry record, its official GitHub release API listing,
and one project documentation page. Failed or client-only pages remain recorded; they cannot be replaced after the
lock.

Every source is assessed on authority, exact historical releases, license, bounded assets, textual and asserted
semantics, published release-diff evidence, multiple semantic-change types, lifecycle/mapping provenance, ambiguity
potential, separable provenance, event scale, and retrospective reconstruction support. Missing or ambiguous evidence
scores false. Availability does not imply permission.

Event evidence is limited to six frozen categories. Eligibility requires at least three, including a definition or
label/synonym change and an obsoletion/replacement or mapping/merge/split change. At least one explicit ambiguity
indicator is also mandatory.

At least two exact historical release assets must be identified in the frozen metadata. Each must be at most 50 MB and
the pair at most 100 MB. These are future-design feasibility fields, not authorization to follow the asset links.

## Why total term count is excluded

V216 showed that a 20,000-term threshold could fail while 197 eligible change records survived. V217A therefore does
not replace that threshold with one calibrated to 15,719. It removes total ontology size from source eligibility and
requires direct metadata evidence about event diversity, release identity, provenance, and bounded assets instead.

## Selection and claim boundary

At most one source may be selected. If several pass, the frozen priority is Mondo, then Gene Ontology, then Cell
Ontology. Priority reflects the preregistered focus on mapping, merge/split, and disease-boundary phenomena; it is not
adapted after the census.

A pass authorizes only a separate payload-design protocol. It does not authorize a payload download, V216/V213
protected use, deterministic method, model, registration, mutation, action, or execution. Historical curator artifacts
remain evidence about their own published semantics, not the intended meaning of a new speaker.

If no source passes, the external retrospective source branch stops without changing URLs, candidate families,
dimensions, thresholds, or gates.
